# КружИИво

[Репозиторий на GitHub](https://github.com/mrasos675-oss/kruzhivo) · [Конкурсная версия](https://github.com/mrasos675-oss/kruzhivo/tree/1aec734cfa61f2fd0e84351a5cb6e70e5dc9a9ca)

## Версии и зависимости

- Git, Node.js **22.19.0 или новее** и npm. Запуск проверен на **Node.js 24.13.1** и **npm 11.8.0**.
- Зависимости описаны в [package.json](package.json). Команда `npm ci` установит версии из [package-lock.json](package-lock.json).

## Запуск

1. Клонируйте репозиторий, установите зависимости и запустите сервер.

   ```sh
   git clone https://github.com/mrasos675-oss/kruzhivo.git
   cd kruzhivo
   npm ci
   npm start
   ```

2. Откройте [http://127.0.0.1:4310](http://127.0.0.1:4310). Для локального запуска ключ API не требуется.
3. Чтобы остановить сервер, нажмите **Ctrl+C** в терминале.

## Описание системы

КружИИво помогает проводить антикоррупционную экспертизу проектов нормативных правовых актов. Система выделяет возможные риски, показывает цитаты и возражения, сохраняет решения специалиста и формирует отчёт. Проверка проходит в таком порядке. **Аналитик → Проверяющий → Редактор → решение человека**. Исходный документ автоматически не изменяется. Выводы ИИ предварительные.
