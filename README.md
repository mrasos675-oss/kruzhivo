# КружИИво

[Открыть действующий сайт «КружИИво»](https://kruzhivo-github.vercel.app/)

На сайте доступен полный сценарий проверки, включая реальный анализ документов. Подключение к ИИ через Polza уже настроено на сервере, поэтому вводить свой API-ключ не нужно.

[Репозиторий на GitHub](https://github.com/mrasos675-oss/kruzhivo) · [Конкурсная версия](https://github.com/mrasos675-oss/kruzhivo/tree/1aec734cfa61f2fd0e84351a5cb6e70e5dc9a9ca)

## Описание системы

КружИИво помогает проводить антикоррупционную экспертизу проектов нормативных правовых актов. Система выделяет возможные риски, показывает цитаты и возражения, сохраняет решения специалиста и формирует отчёт.

- **Аналитик** ищет признаки коррупциогенных факторов и указывает фрагменты документа.
- **Проверяющий** оценивает замечания с учётом других положений документа и доступных оснований.
- **Редактор** предлагает формулировки для замечаний, прошедших перепроверку.
- **Специалист** рассматривает предложения и принимает итоговое решение. Исходный документ сохраняется в первоначальном виде.

## Версии и зависимости

Установите **Git** и **Node.js 22.19.0 или новее**. Менеджер пакетов **npm** входит в установку Node.js. Локальный запуск проверен с **Node.js 24.13.1** и **npm 11.8.0**.

Откройте терминал (на Windows можно использовать PowerShell) и выполните:

```sh
git --version
node --version
npm --version
```

Каждая команда должна вывести номер версии. Если команда не найдена, установите соответствующую программу и откройте новое окно терминала.

Зависимости перечислены в [package.json](package.json), их точные версии закреплены в [package-lock.json](package-lock.json). Команда `npm ci` установит их автоматически. Для загрузки пакетов потребуется доступ к реестру npm. Для локального запуска достаточно указанных инструментов. Отдельная база данных, облачное хранилище и ключ API не требуются.

## Как запустить проект

1. В терминале откройте папку, в которую хотите скачать проект, и выполните:

   ```sh
   git clone https://github.com/mrasos675-oss/kruzhivo.git
   cd kruzhivo
   ```

   По умолчанию откроется актуальная ветка `main`. Если нужно воспроизвести именно конкурсную версию, выполните следующую команду перед установкой зависимостей:

   ```sh
   git checkout --detach 1aec734cfa61f2fd0e84351a5cb6e70e5dc9a9ca
   ```

2. Находясь в папке `kruzhivo`, установите зависимости и запустите сервер. Дождитесь завершения первой команды перед запуском второй.

   ```sh
   npm ci
   npm start
   ```

3. Оставьте терминал открытым. Когда сервер выведет локальный адрес, откройте [http://127.0.0.1:4310](http://127.0.0.1:4310) в браузере на том же компьютере. Должна открыться главная страница «КружИИво».
4. Чтобы остановить сервер, вернитесь в терминал и нажмите **Ctrl+C**. Для следующего запуска в той же папке выполните `npm start`.

### Подключение ИИ для локальной проверки

На действующем сайте используется языковая модель **DeepSeek V4.1 Flash** с открытыми весами через провайдера **Polza AI**. Веса опубликованы под лицензией MIT. [Модель на Hugging Face](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) · [Модель в каталоге Polza AI](https://polza.ai/models/deepseek/deepseek-v4.1-flash-1017)

**Облачная модель через Polza AI.** Скопируйте `.env.example` в `.env` в папке проекта и задайте параметры ниже. Замените `YOUR_POLZA_API_KEY` своим ключом из кабинета Polza AI. Перезапустите приложение командой `npm start` и запустите новую проверку. Храните ключ в локальном `.env`.

```dotenv
LLM_PROVIDER=polza
LLM_MODEL=deepseek/deepseek-v4.1-flash-1017
LLM_API_KEY=YOUR_POLZA_API_KEY
```

**Собственный сервер модели.** Скачайте открытые веса и разверните модель по [инструкции DeepSeek по запуску](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash/tree/main/inference). Учитывайте требования к оборудованию для выбранной конфигурации. Для подключения к «КружИИво» серверу модели нужен совместимый с OpenAI API Chat Completions по публичному HTTPS-адресу с авторизацией. Укажите в `.env` следующие параметры и перезапустите приложение.

```dotenv
LLM_PROVIDER=custom
LLM_PROTOCOL=chat-completions
LLM_BASE_URL=https://model.example.com/v1
LLM_MODEL=YOUR_SERVED_MODEL_ID
LLM_API_KEY=YOUR_MODEL_SERVER_API_KEY
```

Текущая версия «КружИИво» принимает только публичные HTTPS-адреса API. Подключение напрямую к `localhost` или адресу частной сети потребует доработки приложения. Самостоятельное развёртывание модели с проектом не проверялось.

Если `npm ci` сообщает, что `package.json` отсутствует, проверьте, что вы в папке `kruzhivo`. Если запуск завершился с ошибкой `EADDRINUSE`, порт 4310 занят. Остановите предыдущий экземпляр приложения или освободите порт и повторите `npm start`.
